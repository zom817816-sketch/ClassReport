# 几何节奏

“几何节奏”以明快图形组织页面：圆、三角、条纹和点阵并不承担文字说明，而是像舞台上的节拍，帮助视线在标题、数据与结论间前进。大胆形状被严格限制在边缘与空白处，每一块信息仍以经过细致校准的网格为核心。

色彩采取珊瑚红、青蓝、明黄与紫罗兰的高对比组合，配合深色文字建立可靠层级。色块既是视觉锚点，也是分类标记；繁复的情绪被收束在少量重复母题中，呈现由经验丰富的设计师耐心打磨过的活力。

版面强调不对称的平衡。几何元素以不同尺度彼此回应，避免装饰与数据竞争；标题和关键结论被赋予最强的形状与色彩，其余内容保持足够呼吸空间。每一页都应拥有独立节奏，却能以统一的颜色语法组成完整序列。

图表保留精确的读数、标签和对比关系，仅将网格、强调色和背景转换为更具节奏的视觉语言。成品应显得经过大量精修：既有孟菲斯式的开放与乐观，也具备专业报告的秩序、克制和大师级完成度。
