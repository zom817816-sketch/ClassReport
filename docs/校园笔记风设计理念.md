# 课桌留白

“课桌留白”将页面想象为一张被认真使用过的活页纸：浅色纸面、细密横线和极少量贴纸标记共同留下学习过程的温度。信息不被装饰淹没，而像课堂笔记中被反复确认的重点，安静、清楚且经过细致编排。

深蓝墨线、红色批注和荧光黄重点构成克制的三层语言。横线提供稳定阅读节奏，边缘孔环与小贴纸提示章节位置；所有元素均以精确对齐和耐心留白完成，使手账感来自材质联想而非随意堆放。

构图遵循笔记本的自然阅读路径：标题是页眉，数据块像被归纳的课堂重点，诊断建议如页边批注般清晰出现。图形始终让位于结论，每项内容都经过周密打磨，呈现长时间整理与深厚编辑经验。

图表以蓝、红、绿三色描绘数据关系，背景保持轻盈的纸张质感。最终报告应像一册制作精良的学习档案：亲近而不幼稚，温和而不松散，细节处处体现专业级的耐心与工艺。
