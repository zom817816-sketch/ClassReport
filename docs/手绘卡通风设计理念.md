# 纸间成长

“纸间成长”把信息页视作一册被认真保存的学习手账：柔和的纸张底色、带有轻微起伏的墨线和圆润的色块，让理性的分数与诊断拥有亲切、可亲近的温度。页面不追求稚拙的堆砌，而以克制的手绘痕迹建立一种经过细心雕琢的轻松感。

空间采用清晰的阅读轨迹。标题像被荧光笔轻轻划出的重点，数据像贴在纸上的便签，图表保留足够的留白以维持判断的准确性。每一处卡片、分隔线和页脚都经过细致对齐，使活泼的视觉语言仍然服务于报告的阅读效率。

配色来自课堂文具：奶油纸、柠檬黄、珊瑚粉、薄荷绿与紫葡萄色共同构成低饱和而明快的节奏。色彩只承担定位与强调，不替代文字信息；深色墨线与加粗标题保证打印与屏幕阅读时始终清晰。

装饰被控制在角落、标题与信息块周边：星点、圆点和简短的双线勾勒像随手留下的学习标记。它们以精确而节制的方式重复，让整份多页报告像由经验丰富的设计师长时间打磨的一册完整手账，而非彼此无关的页面。

图表延续同一语言：数据的比例、标签和对比关系不被牺牲，只将背景、网格和强调色转换为更柔和的文具色。最终的视觉既具手作亲和力，也保留专业报告应有的可信度、秩序与精工感。
