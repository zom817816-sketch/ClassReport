教培机构开发一款教师端使用AI对学生的课程情况分析报告的应用，并发送给学生
- 对接业务人员，获取真实场景和需求
    - 业务背景和目标
    - 当前教师是如何给学生反馈课程情况的？用什么工具？
    - 这份报告的 核心目的 是什么？（续课转化？学情通报？家长沟通？合规留痕？）
    - 谁是报告的 实际阅读者 ？学生本人？家长？班主任？
    - 期望 多久出一次报告 ？（每节课？每周？每月？学期中？）
    - 覆盖哪些 学科/学段 ？（K12？考研？语言培训？）
    - 报告内容与结构
        - 一份标准报告包含哪些 模块/维度 ？（出勤、成绩、课堂表现、作业、错题、学习建议…）
        - 每个维度的数据 从哪来 ？（教务系统？教师手动录入？直播/录播平台？作业系统？）
        - 报告中需要哪些 可视化 元素？（分数条、雷达图、趋势线、错题热力图…）
        - 是否需要 AI 自动生成 文字点评/学习建议 ？还是教师全部手写？
        - 不同年级/学科的报告模板是否 差异化 ？差异在哪里？
        - 报告的 篇幅 大概多长？（一页 PDF？多页网页？）
    - 报告生成流程
        - 生成过程中教师能否 编辑/修改 自动生成的内容？哪些部分可改？
        - 一份报告生成需要多长时间？是否有 时效要求 ？
        - 报告生成失败或数据缺失时， 容错策略 是什么？
    - 发送与触达
        - 通过什么 渠道 发送？（微信/钉钉/企业微信/短信/邮件/机构 App 内信）
        - 发送的 触发方式 ？（生成即发？教师点击发送？定时批量发？）
        - 发送后需要 已读回执 吗？教师能否看到谁看了、谁没看？
        - 学生/家长能否 回复评论 ？教师是否需要在应用内处理反馈？
        - 报告是以 附件形式 发送还是 链接/网页 形式？
    - 角色与权限
        - 教师能看到 哪些学生 的数据？（只带的班？同年级？全校？）
        - 教师能否 撤销/撤回 已发送的报告？
        - 历史报告如何 归档与追溯 ？保留多久？
    - 优先级与 MVP
        - 第一个版本 必须有 哪些功能？哪些可以后续迭代？
        - 成功的 衡量标准 是什么？（教师使用率？续课率提升？发送覆盖率？）
